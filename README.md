## Open-Source Headless CMS

- [ApostropheCMS](https://apostrophecms.com/) - Open-source headless CMS and website builder based on Node.js for developers and content editors. Offers a headless API and an in-context editing interface. Free to self-host with paid support available. - [Cockpit](https://getcockpit.com/) - Open-source headless CMS written in PHP for self-hosted deployments for developers and small teams. - [Directus](https://directus.io/) - Open-source data platform that wraps SQL databases with a headless CMS interface for developers and data teams. - [Ghost](https://ghost.org/) - Open-source publishing platform and headless CMS for professional blogs and newsletters for publishers and writers. - [Payload](https://payloadcms.com/) - Open-source TypeScript headless CMS and application framework for developers and product teams. Self-hosted with a flexible admin UI and local file storage. Offers a free core and paid cloud services. ([Read more](/details/payload.md)) `Open Source` `Self-Hosted` `TypeScript` `API` `Free Plan`
- [Squidex](https://squidex.io/) - Open-source headless CMS built on .NET and Azure Functions for developers and DevOps teams. Provides a REST API, asset management, and role-based access control. Self-hosted and free to use. ([Read more](/details/squidex.md)) `Open Source` `Self-Hosted` `.NET` `API` `Free`
- [Strapi](https://strapi.io/) - Open-source Node.js headless CMS for building APIs for developers and product teams. Self-hostable with a customizable admin panel and plugin system. Offers a free community edition and paid cloud hosting. ([Read more](/details/strapi.md)) `Open Source` `Self-Hosted` `API` `Node.js` `Free Plan`
